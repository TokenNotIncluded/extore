# Extore 0.11.1

商户可以从商品编辑页与商品处理器配置页找到贡献入口，填写用途、输入和输出，一键复制给 AI 的开发提示词，并前往商品处理器仓库提交 PR。复制失败时可在页面选择原文；离开页面或切换身份后旧操作失效。

- 新增公开的静态贡献契约 `GET /api/processor-contributions`。
- 新增离线 `extore processors contribute` 命令，支持中英文提示词与新建私密输出文件。
- 商品处理器仓库提供贡献指南、PR 模板、维护者代码审核归属及可测试的开发脚手架。
- 配置列表为空时说明创建与绑定的下一步；贡献资料输入不会触发外层商品表单提交。

贡献必须经 PR、源码审核、测试和合并，并被 Extore 的固定发布版本收录后才能运行。创建 Fork 或提交 PR 不会安装处理器，也不会新增在线上传或任意仓库执行入口。本版无需数据库迁移。
