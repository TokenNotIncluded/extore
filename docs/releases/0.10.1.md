# Extore 0.10.1

本次新增四个离线商品处理器，输入表单、交付字段和选项都由代码定义。商家选择处理器、创建本店配置并绑定商品后，即可发行卡密，worker 自动完成处理与交付。

| 处理器 | 实用场景 | 交付 |
| --- | --- | --- |
| `csv_summary` | 实验记录或测量数据的总体、分组描述统计 | 双语 Markdown 报告和 JSON 统计 |
| `json_formatter` | API 配置或数据交接前的 JSON 校验 | 格式化 JSON 和结构报告，保留数字原文 |
| `text_cleanup` | 项目条目、名单的空行清理和去重 | 保留首次顺序的文本和实际清理数量 |
| `document_template` | 固定格式的受理记录、项目说明或交付说明 | 本店模板生成的纯文本或 Markdown |

处理器目录固定到 `extore-processors 0.4.0`。上述处理器只使用 Python 标准库，不联网、不调用语言模型，不生成 DOCX/PPTX。复杂文件制作仍可交给已有的 AI CLI 队列。

后台配置支持代码声明的下拉选项、双语说明和可读配置预览。秘密配置继续只写不回读；已发行卡密保留原配置修订。CSV、JSON、模板正文和关闭空白清理的文本现在保留原始首尾空白，由处理器决定如何规范化。

本次加强输入边界、数值精度和成功结果大小检查。CSV 使用有界输入下的 200 位 Decimal 计算；JSON 不通过二进制浮点转换数字；模板只允许声明的占位符且只替换一次。最终成功结果 JSONL 对象最多 100,000 UTF-8 字节，包括信封、所有输出字段和 JSON 转义。

验证覆盖实际沙箱中的建商品、制卡、兑换、自动执行、进度与领取，以及错误输入不消费卡密、配置冻结、店铺隔离、前端选项和结果预算。数据库结构不变，无需业务数据迁移。

配置方法和可执行示例见[商品处理器场景指南](../processor-recipes.md)。
