# Extore 0.11.2

上游商城可以在商家明确授权后导入商品资料、规格和参考价，并按批准的规格额度补充卡密。提供[完整开放协议](../commerce-import-protocol.md)、公开 JSON Schema、Python `CommerceClient`、机器 `extore commerce` CLI 和不联网的完整示例。

- 商家先登记商城名称及精确 HTTPS 回调；授权采用授权码和 S256 PKCE，绑定店铺、当前商品、独立权限、有效期及每规格累计发行额度。新增商品不会自动获权。
- 商品读取只返回展示资料和兑换定义，不包含顾客任务、已有卡密、交付内容或处理器密钥。参考价保持十进制原文，销售平台自行确定实际售价与销售库存。
- 补货使用必填幂等键，同键同正文恢复原批次，不重复扣额度；加密响应可恢复 24 小时，过期 tombstone 阻止再次发行。刷新令牌一次消费并轮换，重放撤销整份授权。
- CLI 的授权事务、令牌与卡密仅使用私有输入和新建 `0600` 输出文件；交换与刷新有持久消费标记和并发锁，不自动重试不确定的操作。店主 CLI 支持登记应用、查看授权和撤销。
- 后台改为按实际权限分组的桌面侧边导航与手机工作区选择。商品列表支持搜索和筛选，创建按需展开；处理器配置先浏览、再编辑，变量、密钥和运行限制逐步展开，减少表单堆叠。

协议没有支付、订单管理、匿名动态注册、自动批准、已有卡密下载或实时销售库存。一卡一文本商品可导入资料，但不能通过此接口凭空发行交付库存。实际商城还需实现安全字段映射、令牌加密存储、连接刷新锁、幂等入库和订单卡密分配；Extore 的测试不代替上游支付验收。

数据库由 schema 21 加法迁移到 22，新增商城授权与补货回执表，保留已有商品、卡密、任务、附件与交付。测试覆盖服务端跨店铺与范围隔离、一次性授权、刷新重放、规格额度、恢复清理，以及真实后端与 SDK 的完整授权、读取、补货、恢复、刷新和撤销闭环；公开 schema 与文档 JSON 示例同步验证。前端另外验证移动布局、异步页面状态、表单取消与秘密字段边界。
