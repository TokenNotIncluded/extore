# Extore 0.11.0

本版改进流程配置与开发接口，保持任务图 v1、私有 Worker 协议 v2 和已有发行快照兼容；无需数据库迁移。

- 配置页提供流程图、步骤检查器、可视化条件分支与字段映射、失败和超时路径。服务端检查显式草稿，不创建卡密或任务；普通商品继续使用简单兑换。
- 公开结构 JSON Schema，新增离线 `workflow schema` / `workflow validate` CLI；完整语义校验复用发行时的验证器。
- Python SDK 新增 `FlowDefinition` 和绑定当前执行身份的 `FlowExecution`，覆盖开始、进度、成功、失败和附件操作；结果幂等 ID 仍由调用者明确指定。
- 新增流程开发指南及三问、文件交付、选择拒绝的可执行校验示例。
- 修复展示与结束节点的字段别名在运行时未追溯真实来源的问题。附件权限、敏感输入有效期及最近完成来源均沿用实际源节点。
- 文本交付支持复制原文、本地下载 TXT/JSON；切换领取上下文或销毁后旧控件失效。

处理步骤超时仍会终止并等待商家核实，不能据此推断外部动作未发生。新版本不自动执行图中的代码或持续调用 AI；队列 AI 和私有 Worker 仍需商家授权并自行运行。
