# Extore 0.8.2

商品回收站支持清空和逐项彻底删除。确认后商品不能通过页面或 API 恢复；已有卡密、任务、领取链接、交付附件和审计记录保留，用于继续履约。这项操作不会释放交付文件占用的空间，附件清理由交付销毁和存储保留策略处理。

`product.purge` 是独立权限。旧管理链接和既有 AI 授权不会自动获得它，商品编辑、删除与恢复权限也不能代替它。

批量清空按店铺执行，只处理确认时明确选中的商品 ID。后来进入回收站的商品不受影响；正在使用的商品、越权商品或混合店铺请求会整批拒绝。

CLI 支持 `extore admin product purge --product PRODUCT_ID --yes` 和 `extore admin trash empty --yes`。超级管理员清空时须用 `--shop SHOP_ID` 明确选择店铺。商品管理授权可使用相应的 `extore manage` 命令，只作用于该授权商品。缺少 `--yes` 时在本地拒绝，不发送写入或续期请求。

普通商品列表和回收站不再显示彻底删除的商品。队列与卡密历史使用 `history` 商品视图，继续查找原有商品的记录；它不会重新开放商品配置或新卡密发行。
