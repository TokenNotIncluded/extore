# Extore 0.11.3

网站内置的队列、进度看板、店主与处理器配置提示词统一要求安装 `extore>=0.11.3` 并检查实际版本，补充代理、私有 CA 与设备申请冲突的处理说明。店主提示词补充离线流程校验、处理器配置与商城接入命令入口，顾客操作说明区分多步流程、交付后修改和失败重试。

- 合入远程 CLI 修复：`NO_PROXY` 支持 IPv4/IPv6 CIDR，且只匹配 IP 字面量；`--ca-bundle` / `EXTORE_CA_BUNDLE` 显式添加可信 CA，目标 HTTPS 与 HTTPS 代理继续校验证书和主机名。
- 设备范围申请返回 409 时，CLI 对固定协议错误区分商品已删除、永久移出回收站和授权版本变化。未知冲突保持通用说明，不再从 409 推断授权容量耗尽，不输出任意服务端正文或秘密。申请上限仍按服务端 429 处理。
- 同步远程已合并的初始化 schema 检查、冗余兼容分支清理与文档修正；保留现有店铺、商品、卡密、任务及交付，不改变授权范围。

此版本不自动恢复商品、不代替商家批准设备，也不因升级重新创建申请。数据库沿用 schema 22。
