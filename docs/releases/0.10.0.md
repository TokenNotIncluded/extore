# Extore 0.10.0

卡密现在可以绑定商家自定义属性。制卡时先取规格属性，再合并该批次的覆盖值，并固定属性与权益配置；之后修改商品不会改变已经发行的卡密。属性支持文本、数字、布尔值和空值。

可重复领取的内容商品可以选择一个整数属性作为交付后的修改额度，例如各规格分别包含 0、1、3 次修改。顾客在原领取链接提交修改建议，任务重新进入同一商品队列；网页、CLI、商品处理器与 Webhook 都能读取属性、剩余额度和本轮建议。技术失败重试沿用本轮额度，不额外扣次数。

同一修改请求重发不会重复扣减，并发请求只接受一次。上一轮工人的延迟上传、进度或完成操作无法覆盖新一轮。修改处理中仍可领取先前成功的版本；主动销毁会清除所有版本和附件。历史文件和修改建议继续受卡密、店铺和全站容量限制。

网页新增属性与权益编辑、顾客修改入口和交付版本选择。CLI 可用 `cards issue --attributes-file` 覆盖属性，`customer revise --message-file` 提交修改建议，`customer reveal --revision` 领取历史版本。AI 默认获得当前任务与最近交付的摘要，完整版本列表按需读取。

```sh
uv tool install --upgrade extore==0.10.0
```

既有设备授权继续有效。旧卡密不会自动获得新配置的修改权益；需要发行新卡密。首版修改权益支持队列、脚本和 Webhook 的重复领取内容商品，一卡一文本、仅服务状态和多步骤交互流程暂不支持。
