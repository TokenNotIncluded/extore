# Extore 0.9.1

店铺是一座工厂，每个商品队列是一个电子车间。管理者可分别配置工厂、车间标语，用来说明任务处理偏好。`manage next` 自动返回当前标语，`manage instructions --product PRODUCT_ID` 可单独读取；标语与顾客输入分开，不改变已批准的权限。商品处理器和私有 Worker 同样能读取工作提示词。

进度看板展示工厂、车间标语和实际进度，减少卡片边框、增加留白。长标语可展开，工厂标语在看板编辑，车间标语在商品配置编辑。顾客页面不显示工作提示词。

卡密按生成、导入批次显示文件夹与数量，进入文件夹后查看卡密。支持整批删除、还原和永久清理。删除批次会停用仍可兑换的未开始卡密，保留已提交任务与交付；永久清理先预览，只移除没有任务的卡密，已有订单不会随着库存目录一起消失。详见 [批次管理](../card-batches.md)。

每家店铺自动拥有当前 `main` 发行标识。替换发行标识不会原地改写旧卡密绑定的公钥、地址或路径。历史标识和路由可以收起查看、预览和清理，仍有存续卡密依赖的配置会保留。

首页统一处理普通卡密和签名代理卡密，移除独立 `/proxy` 页面。代理卡密在浏览器验签后跳到发行站，完整下游卡密不发送到入口站后端。旧路径兼容跳到首页。

```sh
uv tool install --upgrade extore==0.9.1
```

既有设备授权继续有效，不用重新登录。较早 CLI 可继续使用其原有功能；读取新版看板和工作标语请升级。
