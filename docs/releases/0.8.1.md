# 0.8.1 更新说明

商品现在可以删除到回收站，也可以恢复。删除后不再公开展示，默认商品列表隐藏它；该商品不能继续发行卡密、导入文本库存、更新配置、生成新管理链接或作为复制模板。

已发行的卡密、任务、交付内容、领取链接和原有处理授权继续有效。队列仍能查看和处理这些任务；删除不会撤销订单或中止正在执行的外部操作。恢复会沿用原商品配置，包括原来的公开展示状态。回收站不是永久擦除或存储清理。

店主和平台管理员可以操作。商品管理链接与设备需要明确授予新增的 `product.delete` 权限；现有编辑、处理和完整管理链接不会自动获得这个新权限。删除须在网页确认，CLI 须加 `--yes`；删除、恢复按实际状态变化记录审计。

```sh
extore admin product delete --product PRODUCT_ID --yes
extore admin products --view deleted
extore admin product restore --product PRODUCT_ID
```

商品设备使用同名 `manage` 命令；列表的 `--view` 支持 `active`、`deleted` 和 `all`。HTTP 删除和恢复端点见[店主 CLI](../cli-owner.md#商品回收站)。原有设备签名、店铺隔离和权限边界仍适用。

数据库迁移仅新增 `product_lifecycle` 表，schema 从 14 升为 15；原有业务表、商品配置和卡密不重写。升级前照常备份数据库、附件和密钥。
