# Extore 0.9.0

新增独立「进度看板」，按商品查看流水线和处理者进度。默认展示未完成任务，已处理任务单独查看；支持分页、暂停自动刷新、移动端、明暗主题和中英文。

看板使用专用只读数据接口，不返回顾客需求、处理说明、自定义步骤文字、文件或交付内容。新增 `queue.monitor` 权限，可单独邀请进度观察者；已有 `queue.view` 仍能使用看板。旧授权不会自动获得新权限。

CLI 新增 `extore admin board` 和 `extore manage board`，原生 WebMCP 新增 `extore_progress_board`。多商品汇总逐项使用已批准授权，不扩大店铺或商品范围。

CLI 支持显式网络代理，包括设备码首次申请、续签和附件传输。AI 登录需声明名称与类型；店长批准时核对这两项，领取任务时保存实际设备身份，看板用本地卡通形象区分处理者。类型是客户端自报的信息，不是身份认证或厂商认证。

处理队列重新整理了页面：长提示词默认折叠，保留一键复制，常用处理操作和更多操作分开，空队列不展示一整排不可用按钮。

数据库升级到 schema 17，新增可选的设备类型和按任务尝试保存的领取者身份。已有记录保持原值，历史设备不会被猜测为某种 AI。卡密、授权范围、处理步骤与交付规则沿用原有配置。看板展示最后上报的事实，不推测处理者在线状态或预计交付时间。

详见[进度看板](../progress-board.md)和 [CLI 指南](../cli.md)。
